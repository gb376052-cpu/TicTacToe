# ❌⭕ Tic Tac Toe Game

A classic and interactive Tic Tac Toe web game built using HTML, CSS, and JavaScript. Enjoy a smooth two-player gaming experience right in your browser with a clean and modern user interface.

## ✨ Features
* Classic two-player gameplay (Player X and Player O).
* Turn indicator and instant winner/draw detection.
* Clean, minimalist, and fully responsive user interface.
* Reset/Restart functionality to play multiple rounds.

## 🛠️ Tech Stack
* **HTML5**: Game board structure and layout.
* **CSS3**: Styling, grid design, and visual effects.
* **JavaScript (ES6)**: Game logic, win-condition checks, and DOM manipulation.
